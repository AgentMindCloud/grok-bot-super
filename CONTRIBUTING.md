# Contributing to Grok Bot Super

Thank you for helping make Grok Bot more powerful and easy for everyone.

## How to add a Skill

1. Create a new folder under `/skills/your-skill-name`
2. Add a `SKILL.md` file following the template in `/skills/_template/SKILL.md`
3. Keep the skill self-contained and easy for a Grok Bot to learn by observation or reading.
4. Open a PR.

Skills should be practical, clear, and safe. Prefer step-by-step instructions the Bot can follow or demonstrate.

## Skill Guidelines

- Clear title and short description
- When to use it
- Required tools / logins (if any)
- Exact steps or decision rules
- What the Bot should return
- Approval boundaries (what always needs human confirmation)

## Code of Conduct

Be kind. This is a free community project for the Grok ecosystem.
