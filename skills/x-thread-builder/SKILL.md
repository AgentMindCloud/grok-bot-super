# X Thread Builder

Turns a rough idea or long text into a high-signal, ready-to-post X thread.

## When to use

User has an idea, draft, article, or notes they want turned into a strong X thread.

## Required access

None. Pure writing skill. (Bot can later post if user has given permission.)

## Steps

1. Understand the core insight and intended audience.
2. Craft a strong opening hook (first 1–2 posts).
3. Break the content into tight, readable posts (max ~280 chars each).
4. Use rhythm: short → short → longer insight → short CTA.
5. End with a clear call to action or question.
6. Offer 1–2 alternative hooks if requested.

## How to validate

- Each post is within ~280 characters.
- The hook is in the first 1–2 posts.
- Nothing was posted.
- No facts were added that were not in the source idea.

## Always ask for approval when

- Posting the thread live
- Using the user’s personal voice on sensitive topics

## Expected output

Numbered posts ready to copy-paste, plus optional image prompt ideas.
